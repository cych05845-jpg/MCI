建議做法（大量傷患／演練）：Google 試算表 + Apps Script。 建立試算表 → 擴充功能 → Apps Script → 貼上隨附的 Code.gs → 部署為「網頁應用程式」（執行身分：我；存取權：任何人）→ 把網頁應用程式 URL 貼進上方端點。金鑰請設定於 Apps Script「專案設定 → 指令碼屬性」，屬性名稱 API_KEY，值需與此處填的金鑰相同。 精準語音：另於指令碼屬性新增 GEMINI_API_KEY（Google AI Studio 取得），可加 GEMINI_MODEL 指定模型（預設 gemini-2.0-flash）；語音由 Apps Script 轉送 Gemini，金鑰不會出現在前端。 對 Google 端點送出時金鑰會放在 JSON 內（欄位 apiKey），不使用 Authorization 標頭。 開啟同一個 URL 即為即時傷患清單看板（每 10 秒自動更新）；網址加上 ?view=admin 即為行政管理面板（含傷患登錄清單、去向下拉可直接修改寫回）。人員名單維護於試算表「人員」分頁。
按「儲存/送出」時，本工具會將下列 JSON 以 POST 傳送至端點；未設定端點或斷網時，紀錄保存在本頁「紀錄/統計」（可匯出 CSV/JSON 事後補傳或交院內系統匯入）。 正式 HIS 介接需由院內資訊室／廠商開設接收端點並處理 CORS 與帳號驗證。
